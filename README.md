
# Coaching Center Management

A full-stack coaching center management
application built with React, Express.js,
and Oracle Database.

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Recharts
- Lucide React

### Backend
- Node.js
- Express.js
- Oracle Database Driver
- Helmet
- CORS
- Express Rate Limit

### Database
- Oracle Database 23ai Free

## Application Portals

1. Admin Portal
2. Teacher Portal
3. Student Portal

## Project Structure

- frontend: React application
- backend: Express API
- database: Oracle SQL scripts

## Development Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

## Environment Configuration

Configure frontend/.env and backend/.env
before starting the application.

Never commit actual environment secrets.
